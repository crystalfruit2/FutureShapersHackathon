## 3. Technical wow (feasibility-checked for UNO R3 + this kit)
**Tier 1 — build:**
1. **Serial-tethered live BMS dashboard** (laptop: Python+pyserial+Flask/SSE; UNO: newline JSON-ish lines, `F()` macros, NO ArduinoJson on UNO). Floor-plan view, event log, **authenticated commands back down** (rolling counter + CRC/XOR MAC). ≈2–3h with scaffold prepped. This IS Honeywell's supervisory-layer product shape.
2. **Attack-then-defense suite** (total ≈3h): (a) IR remote recast as ATTACKER's tool — fixed-code replay visibly rejected ("UNAUTHORIZED RF CMD") — **true rolling-code IR infeasible: kit remote is fixed NEC codes, don't burn hours**; (b) serial replay → "STALE COUNTER — REPLAY DETECTED"; (c) PIN brute-force lockout, attempts survive power-cycle via EEPROM; (d) **chained-CRC EEPROM audit log** — dashboard "Verify log" walks the chain, corrupt one byte live, chain breaks red at exact record (invite a juror to pick the entry); (e) tilt tamper on enclosure/icon; (f) fail-secure boot.
3. **Fault-tolerance theater**: unplug DHT11 live → "OFFLINE — degraded mode" → auto-recover on reconnect; `pulseIn` WITH timeout; AVR watchdog "freeze button" → 2s reset → state restored from EEPROM. The most Honeywell-shaped 30 seconds available.
**Tier 2 (only if Tier 1 lands by Wed noon):** zone-addressed logic on dashboard floor plan; EWMA anomaly detection (2 floats/channel — NOT ring buffers, 2KB RAM); sensor spoof detection (flame sensor triggers on IR remotes — turn the bug into the spoof demo: flame signal without DHT temp corroboration = "possible spoof").
**Hardware gotchas (all verified):** MQ4 needs 24–48h burn-in + ≥10 min warm + report ratio-over-baseline not fake ppm; power budget kills before RAM (MQ4 heater ~150mA + servo spikes + relay → brownouts; actuators on kit's supply module, common GND); **pin famine**: parallel LCD+keypad = 14 pins & D0/D1 reserved for dashboard → need I2C LCD or demote LCD; `tone()` vs IRremote both want Timer2; DHT11 max 1 read/2s; PIR needs 30–60s stabilization + retrigger dead-time; KY-020 bounces violently (N-consistent-samples debounce).

## 4. Jury model (Honeywell Romania)
- Mixed jury likely: application/field engineers, tech support leads, maybe cyber, maybe HR. **"FutureShaper" is Honeywell's employer-brand word — this camp is a hiring funnel; 5/7 rubric items are reflection because reflection is their hireability proxy.**
- Best proxy = TeChallenge (same jury pool): rewards **modest, WORKING, honestly-framed prototypes with one memorable original element**; winners funneled to internships. Criteria: creativity, innovation, practical applicability.
- No public record of past FutureShapers winners exists (searched EN+RO) — nobody can copy last year.
- 12-min structure: 0:30 hook → 4 min continuous-scenario demo → 1.5 optional features → 1.5 steps-to-success (picture) → 1.5 challenges (problem→tried→fixed) → 1 architecture → 1 experience (ONE specific named moment, zero adjectives) → 1 lessons + callback close.
- Ranked psychology: (1) visibly hit every rubric/mandatory checkbox, (2) genuine reflection, (3) polish/confidence, (4) sponsor alignment via VOCABULARY ("life safety", "supervisory layer", "OT security", "optimize energy while maintaining occupant comfort" — lifted from Honeywell's own 2026 hackathon brief).
- Penalty traps: loose crypto claims in front of OT-security sellers ("an UNO can't do TLS — here's what real hardening needs" = points); no demo fallback; skipping soft rubric items; ANY invented statistic.

## 5. Winning-project patterns (15 sourced examples)
- **Physical embodiment beats dashboards**: Siemens Challenge gold = robotic flower displaying air quality; runner-up = scale model of the venue ([Birmingham](https://www.birmingham.ac.uk/news/2022/school-of-engineering-hosts-siemens-hackathon-birmingham-students-take-home-gold))

- **Cyber theater pattern**: DEF CON thermostat ransomware + Nest "Hello, Dave" — the attack must be REAL on your own hardware, visible on the device's display, then blocked. No jury rewards fake security theater.
- **Component off-label, narrated proudly**: Hackaday runs a whole contest on it; Wheezer won Intel Hacks Grand Prize partly on outsmarting the board's ADC limit
- **Anticipation beats reaction** (Solaris, EnerHack): trend-based pre-alerts > thresholds
- **Retrofit framing wins** (Wise Chameleon, Alexa+Arduino challenge)
- Unanimous demo-risk advice: lock code ~2h early, rehearse exact run ≥5×, record backup video twice, hardcode the demo path, mock transparently
- Romanian corporate jury (Cluj 2025 @ Bosch): explicitly cited "highly-polished prototype", vision, adaptability
